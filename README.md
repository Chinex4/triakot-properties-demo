# Triakot Properties — Website Concept Demo

A premium responsive real-estate website concept created for Triakot Properties.

## Demo features
- Editorial luxury real-estate visual direction
- Responsive desktop and mobile layouts
- Property discovery/search interface
- Featured property cards
- Lagos and Abuja location discovery
- Buyer trust / due-diligence section
- Diaspora buyer experience
- Inspection / enquiry CTA
- Scroll reveal interactions and saved-property interaction

## Run locally
No build step is required. Open `index.html` in a browser, or serve the directory with any static HTTP server.

## Deployment
This project is static and can be deployed directly to GitHub Pages, Vercel, Netlify or Cloudflare Pages.

> Concept/demo only. Listing content and photography are placeholders and should be replaced with Triakot Properties' approved production assets and verified property information before production use.
